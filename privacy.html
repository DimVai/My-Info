Πολιτική Απορρήτου - Τα στοιχεία μου

Τελευταία ενημέρωση: 7 Ιανουαρίου 2026

Η παρούσα Πολιτική Απορρήτου περιγράφει τις πρακτικές σχετικά με τη συλλογή, χρήση και κοινοποίηση πληροφοριών όταν χρησιμοποιείτε την εφαρμογή μας. Κατανοούμε τη σημασία της ιδιωτικότητας και δεσμευόμαστε να προστατεύουμε τα δεδομένα σας.

1. Συλλογή Πληροφοριών

Η εφαρμογή δεν συλλέγει ούτε αποθηκεύει προσωπικά δεδομένα σε δικό μας διακομιστή (server) και δεν διαθέτει σύστημα λογαριασμών. Τα δεδομένα που καταχωρίζετε (τιμές στα πεδία) αποθηκεύονται μόνο τοπικά στη συσκευή / εφαρμογή / browser (φυλλομετρητή) σας, μέσω του μηχανισμού τοπικής αποθήκευσης (localStorage).

Τα δεδομένα αυτά παραμένουν αποκλειστικά στη συσκευή σας, δεν διακινούνται μέσω κανενός δικτύου (όπως wi-fi ή internet), δεν μεταφέρονται σε δικό μας server και δεν αποστέλλονται από εμάς σε τρίτους.

1.1 Τοπική αποθήκευση (localStorage)

Η τοπική αποθήκευση (localStorage) είναι χώρος που παρέχει ο browser σας για να αποθηκεύονται δεδομένα στη συσκευή. Μπορείτε ανά πάσα στιγμή να διαγράψετε τα δεδομένα της εφαρμογής διαγράφοντας τα «δεδομένα ιστοτόπου» ή την αποθήκευση του browser για τον συγκεκριμένο ιστότοπο ().

2. Χρήση Πληροφοριών

Δεν χρησιμοποιούμε τα δεδομένα που καταχωρίζετε για κανέναν σκοπό πέρα από τη λειτουργία της εφαρμογής στη δική σας συσκευή. Δεν πραγματοποιείται από εμάς ανάλυση, προφίλ χρήστη ή παρακολούθηση (tracking) των δεδομένων που καταχωρίζετε.

3. Κοινοποίηση Πληροφοριών

Δεν κοινοποιούμε σε τρίτους τα δεδομένα που καταχωρίζετε στην εφαρμογή. Η εφαρμογή δεν έχει δικό μας backend/server για να αποστείλει τέτοια δεδομένα.

4. Ασφάλεια Δεδομένων

Τα δεδομένα αποθηκεύονται τοπικά στη συσκευή / εφαρμογή / browser (φυλλομετρητή) σας. Η ασφάλειά τους εξαρτάται από τα μέτρα ασφαλείας της συσκευής και του browser σας. Συνιστούμε να χρησιμοποιείτε κωδικό / βιομετρικό κλείδωμα συσκευής και να μην μοιράζεστε το προφίλ του browser σας με άλλους χρήστες, εφόσον αποθηκεύετε ευαίσθητες πληροφορίες.

5. Αλλαγές στην Πολιτική Απορρήτου

Η παρούσα Πολιτική Απορρήτου ενδέχεται να ενημερώνεται τακτικά. Οποιεσδήποτε αλλαγές θα δημοσιεύονται σε αυτή τη σελίδα.
